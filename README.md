##### SkillCraft Technology - Data Analytics Internship Task 2



**Project Title**

Data Cleaning and Preparation using Python and Pandas



**Objective**

The objective of this task is to clean and prepare a dataset using Python and the Pandas library.



**Dataset**

Sample Superstore Dataset



**Tools Used**

* Python
* Pandas
* Google Colab



**Data Cleaning Steps Performed**

* Loaded the dataset into Google Colab.
* Examined dataset structure using df.info().
* Identified missing values using df.isnull().sum().
* Checked duplicate records using df.duplicated().sum().
* Removed duplicate rows.
* Converted Order Date and Ship Date columns to datetime format.
* Verified data types.
* Exported the cleaned dataset to a new CSV file.



**Files Included**

* Original Dataset (Sample-Superstore.csv)
* Cleaned Dataset (Cleaned\_Superstore.csv)
* Jupyter Notebook (Task2\_Data\_Cleaning.ipynb)
* Screenshots of data cleaning process



**Outcome**

Successfully cleaned and prepared the dataset for further analysis and visualization using Python and Pandas.
